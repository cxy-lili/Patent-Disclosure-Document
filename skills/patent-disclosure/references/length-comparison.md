# 交底书篇幅及章节增量比较

用于“字数／页数有什么区别”“主要在哪些章节多”。这是只读统计，不保存、转换覆盖或改写原文，也不自动启动技术方案审查。

## 统计版本与口径

- 重新确认两份实际文件及当前打开版本。文档有未保存编辑时，优先统计当前打开内容并简短说明；用户明确要求磁盘版本时，则读取已保存版本。两者不可混用。
- 两份文档使用同一工具、同一范围和同一指标。优先读取 Word/WPS 原生统计；不能把一份的应用字数与另一份的提取文本长度混比。
- 明确区分应用“字数”、字符数（含／不含空格）、纯汉字数和页数。`.split()` 对中文文本的分词数不是文档字数；文件大小、段落数也不能替代篇幅。
- 使用 Word 兼容对象模型时，可核实 `ComputeStatistics` 的统计项：0 为字数，2 为页数，3 为不计空格字符数，5 为计空格字符数。同一统计项可用于文档和实际章节 Range；具体以当前接口支持情况为准。
- 统一是否计入章节标题、表格、脚注／尾注、页眉页脚及数学内容。应用通常不能统计附图图片内部的文字，不将其计为已核对的正文。不同软件对数学对象的计数可能不同，不把线性化公式或 XML 标签长度冒充应用统计。
- 页数按当前排版报告，说明其受字体、行距、公式及附图影响；不能用页数比例推算字数比例。只做统计时不必为了交付文档重新跑整套编辑和渲染流程。

## 全文对比

默认给“应用字数、字符数（不计空格）、页数”的简表；用户只问单项时可只给该项。按用户指定的比较方向计算：

- 差额＝交底书2数值－交底书1数值。
- 增幅＝差额÷交底书1数值；倍数＝交底书2数值÷交底书1数值。
- 基数为0时不计算百分比，直接说明新增数量；负差额明确写减少。

先回答哪个更长、约多多少，再给精确数值与统计版本。不得沿用本案例历史字数或页数当作当前文件的固定属性。

## 按章节找出主要增量

1. 读取两份文档的实际章节标题与边界，区分一级章节、编号条目、实施例小节及公式段。编号形似章节不代表就是章节；结合标题内容和层级判断。
2. 章节从当前标题起到下一同级标题前结束，末章到正文结束；包含下属小节。分别对这些实际范围调用与全文一致的统计项，不用两章起始字符位置之差充当字数。
3. 按内容和标题对齐一级章节；章节被拆分、合并或更名时交代对应关系。不能只按章节序号假定技术内容相同。正文之外的表头或填写信息单列，不静默丢弃。
4. 计算各章差额并按增量排序。将各章字数和未分章内容与全文统计核对；有计数差异时查明范围或边界，不为了凑总数修改结果。
5. 先给增量最大的章节及两份字数、差额。需要时说明其占全文**净增字数**的比例；净增为0或负数时不以此比例说明新增来源。其他章节有删减时，“占净增比例”可能超过100%，应同时给出主要增减项。
6. 再定位该章的具体小节，读原文解释其主要展开了哪些机制或执行条件。表头明确标为“交底书2该小节字数”，不可把其自身字数说成比交底书1多出的字数；有可靠对应范围时才计算小节差额。合计小节时不能重复计入父章。

答复优先使用一个章节差额表和必要的小节说明。不要预设“实施例更多”“背景更长”；这些判断应由统计支持。只需要篇幅定位时，不进一步建议压缩、重写或修改文件。
