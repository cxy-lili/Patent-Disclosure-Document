# 技术领域与语言适配

按原材料选择检查重点，不向原本没有某种机制的方案强行加入图模型、提示学习、训练损失或业务标签。下面是审查维度，不是已经证实的项目事实或必须齐全的章节。

| 技术类型 | 重点核对 |
| --- | --- |
| 软件、算法、人工智能 | 数据及时间可用性、处理流程、维度、训练／推理边界、共享与独立参数、异常及版本管理 |
| 机械、装置、系统结构 | 部件构成、相对位置、连接和配合、动作顺序、输入输出及必要运行条件；文字与结构图一致 |
| 电子、电路、控制 | 信号来源、接口、模块连接、采样／触发和反馈、参数单位、状态切换及异常分支 |
| 材料、化学、工艺 | 组成或原料、范围与单位、步骤顺序、工艺条件、样品／试验条件及可追溯结果；不编造配比和实验 |
| 跨领域组合 | 明确每个部分的作用、接口及共同技术效果，不能用领域名罗列替代实际技术关系 |

对未提供的必要运行条件、参数依据或实验事实，区分审查与授权补全设计。不因换领域而将合理推测当成已完成实验；涉及专业安全规范或现行法律时检索适用的官方资料。

## 语言和法域

- 默认按用户要求及模板输出，中文交底书使用统一中文术语；英文来源可以服务中文编纂。要求英文或双语时统一符号、术语和对应段落，不把机器直译视为技术核验。
- 用户未指定英文术语时，确有必要的缩写首次给完整名称，后续保持一致；不要求所有常用缩写机械展开。
- 语言不决定申请法域。中国交底书习惯结构不等于其他法域的法律要求；用户问外国提交要求时另核实该法域规则，不凭翻译认定满足提交或授权条件。
- 双语比较使用同语言的统计或明确分别计数，避免直接以中文字符数和英文词数比较技术篇幅。
