# 环境与文件格式适配

本 skill 提供工作方法，不附带 Office、OCR、渲染器或联网账户。先检查当前工具能力，再选择路径；客户端支持 skill 不代表具备文档读写能力。

## 环境选择

| 环境 | 优先路径 | 边界 |
| --- | --- | --- |
| Windows，文档正在 Word/WPS 打开 | 可用文档会话、连接器或受允许的应用对象模型 | 先检查当前内容和未保存状态，只操作目标文档，不关闭整个应用 |
| Windows，未打开的 DOCX | OOXML 或可靠 DOCX 库；可用 Office 导出用于视觉检查 | 保留数学对象、关系、页眉页脚，不对占用中的文件强行覆盖 |
| macOS | 可用文档连接器、受允许的应用自动化，或离线 DOCX 处理 | 不使用 Windows COM 假定；使用应用自动化前核实其对象和行为 |
| Linux／容器 | DOCX 库或定点 OOXML；可用 LibreOffice 与 PDF 渲染工具 | 无桌面 Office 不影响文本审查，但原生格式和页数应按实际验证能力报告 |
| 云端／远程代理 | 已上传或明确挂载的文件、已授权连接器 | 不假定能读取用户本机路径；没有文件写入权限时交付修改意见并说明限制 |
| 仅聊天或无执行工具 | 用户提供的正文、图像及可读附件 | 可以分析和提出替换稿，不宣称已改本机原文件或完成不可执行的统计 |

宿主提供托管运行时或文档工具时遵守其依赖和权限规则；普通本地环境使用已安装且允许的工具。不要硬编码某台机器的 Python、Office、临时目录或插件路径，也不为安装 skill 自动安装 Office／LibreOffice 或修改安全设置。

## 文件格式

- **DOCX／OOXML**：先检查实际包格式；替换普通文本时保留 OMML、图片关系及段落属性。段落文本抽取不能代替公式或排版检查。
- **旧 DOC**：先区分二进制文档和错误扩展名的 OOXML。必要时用受支持的 Office 转换内部工作副本；用户要求原位保留格式而工具无法可靠回存时说明具体限制，不把另一个格式冒充原文件。
- **PDF／扫描件**：用于读取、核对和参考。扫描内容可能需要 OCR；低置信度数字、公式和页码要回看原图。PDF 不能作为已保留 Word 可编辑公式的证明。
- **Markdown／纯文本**：可直接编辑与比对；统计时明确字符或自定义口径，不声称等于 Word 应用字数。LaTeX 仅用于该格式或后续支持的公式转换。
- **PPTX／图像／draw.io**：分别提取文字、检查图像和读取原生图元；从截图观察到的修改不能假定已经回写源文件。

优先复用宿主现有的文档渲染器；没有时可用实际可用的 Office 或 LibreOffice 导出 PDF，再生成页图检查。记录软件与版本差异，勿将另一个渲染器产生的页码冒充原应用页码。
